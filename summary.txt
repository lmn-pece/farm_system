农户管理系统项目
    1. 计划项目架构(maven 多模块聚合项目)
        - 模块关系示意图
            · farm                 父(根)项目，负责规划依赖引入
                |--  farm_common   通用项目，存放全局通用功能
                |--  farm_main     主启动项目，用于统筹其他模块并启动项目
                |__  farm_system   核心项目，存放核心业务逻辑

    2. 根据数据库表编写核心业务逻辑   -- farm_system
        - 模块架构图
            · farm_system (按编写顺序)
                |--  entity         实体层 根据数据库表设计类
                |--  mapper         持久层 通过代码实现与数据库的交互
                |--  service        服务层 核心业务处理逻辑
                |__  controller     控制层 对外暴露接口

        - 一般的 在控制层编写时会考虑与前端的数据交互方式，以及业务异常处理
            · 对于数据格式,需设置统一返回格式，本项目为 json 格式， 详见 /farm_common/···/result 包
            · 对于异常处理,主要包括 系统异常 和 业务异常, 详见 /farm_common/···/exception 包

    3. 在本项目实际开发中 是通过 User 表来构建整体链路，然后去补充其他表关系的
       故而此文档以开发顺序来写总结，可能会出现与前文重复的地方

    5. 完成 Security 处理器的编写
        - security 包架构图
            · security
                |-- SecurityConfig                Security总配置类，装配过滤器链与所有自定义处理器
                |-- MyLoginSuccessHandler         登录成功处理器
                |-- MyLoginFailureHandler         登录失败处理器
                |-- MyLogoutSuccessHandler        注销成功处理器
                |-- MyAuthenticationEntryPoint    未登录/凭证失效 401处理器
                |__ MyAccessDeniedHandler         已登录但权限不足 403处理器
